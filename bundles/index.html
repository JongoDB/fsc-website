App Bundles

Pre-curated software stacks ready for deployment

01 — Overview

What Are App Bundles?

Pre-curated, documented software stacks designed for specific missions. Each bundle includes all the tools, documentation, and deployment guides you need to get up and running quickly.

Bundles are designed to work with our Secure Runtime Environment, but can also be deployed standalone or integrated into existing environments.
